Exploring WordPress Customization

Chandler Holloway

October 21, 2026

For this activity I chose the Astra theme and the WP Super Cache plugin. I selected Astra because it is free, lightweight, and highly customizable. While browsing the Featured, Popular, and Latest themes, Astra stood out for its small code footprint and its large library of Starter Templates, which let me begin from a pre-built design instead of a blank page. Through Appearance > Customize I could adjust the site identity, colors, typography, and header and footer layout without writing any code, which turned the plain default look of my site into a more polished and personal design. I chose WP Super Cache because performance is a big part of usability, and this free plugin, maintained by Automattic, speeds up a site by generating static HTML files from dynamic WordPress pages and serving those files to visitors instead of rebuilding each page on every request. Its Easy setup mode made it simple to turn on, and it extended my site with caching that WordPress does not include by default, reducing server load and helping pages load faster. Together, the theme improved how my site looks and the plugin improved how it performs.
